# Federated Learning for Chest X-Ray Classification: project page

A one-page summary of my college major project, live at https://federated-chest-xray.vercel.app.

The study's code and training scripts are in [federated-learning-major-project](https://github.com/prasadchopade/federated-learning-major-project). This repo holds only the page. Every number on it comes from that repo's `docs/results.md` and `docs/method.md`.

## Run it locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## How it's built

The page is a Next.js app, and the content lives in `components/research-page.tsx`. It was generated and edited with [v0](https://v0.app), which pushes its changes to this repo. Every merge to `main` deploys to Vercel.
